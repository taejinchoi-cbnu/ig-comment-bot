# Phase 2 — 웹 (지인이 실제로 쓸 수 있는 최소)

> **상태**: 대기   |   **선행**: Phase 1
>
> **완료 기준**: **지인 1명이 나 없이 자기 게시글에 자동 DM을 건다.**

## 목표

Phase 1로 파이프라인은 돌지만 SQL을 직접 써야 한다. 여기서 사람이 쓸 수 있게 만든다.

완료 기준이 "화면이 다 있다"가 아니라 **"지인이 혼자 해낸다"** 인 이유는,
그게 [`why.md`](./why.md) 원칙 1("개념을 늘리지 않는다")의 유일한 진짜 검증이기 때문이다.
옆에서 설명해줘야 했다면 실패다 — 무엇을 설명해야 했는지 `진행 기록`에 적고 그걸 없앤다.

> 단, 최초 연결(토큰·시크릿 입력)은 App Review를 안 가는 한 어쩔 수 없이 어렵다.
> **그 구간은 내가 대신 해주고, 그 이후부터 "쉬움"을 보장한다.**

## 할 일

### 1. API
- [ ] `auth/` — 가입(상태 `pending`) · 로그인 · JWT · argon2. JWT 서명키는 Secrets Manager
- [ ] `accounts/` — 연결 마법사 3단계
  - [ ] 자격증명 저장(암호화) + `slug`·`verifyToken` 생성 → **webhook URL 반환**
  - [ ] `[연결 확인]` → `GET /me` 토큰 검증 + **`POST /me/subscribed_apps`** → 상태 `connected`
  - [ ] 실패 시 사람이 읽는 오류 (토큰 만료 / 권한 부족 / 계정 불일치)
- [ ] `campaigns/` — CRUD + **게시글 URL 해석** ([`meta-api.md`](./meta-api.md) §5: `/me/media` permalink 매칭)
  - [ ] 매칭 실패 시 같은 응답의 목록을 후보로 반환 (추가 호출 없이)
- [ ] `events/` — 최근 활동 목록 (페이지네이션)
- [ ] 모든 쿼리는 `igAccountId` 스코프. 남의 계정 데이터가 새지 않는지 테스트

### 2. Web (React + Vite + TS + Tailwind)
- [ ] `packages/shared`에 DTO 타입 두고 web·api 양쪽에서 import
- [ ] **로그인/가입**
- [ ] **인스타 연결** — 마법사. Meta 앱 만드는 법 안내 + webhook URL/verify token **복사 버튼**
- [ ] **대시보드** (아래 구조)
- [ ] 정적 빌드 → S3 + CloudFront (Phase 1 템플릿에 S3·CloudFront 오리진 추가)

### 3. 대시보드 구조

```
┌──────────────────────────────────────────────────────────┐
│ @myaccount 연결됨          오늘 12건 · 이번 달 340건 발송 │
├──────────────────────────────────────────────────────────┤
│  [ + 자동 DM 추가 ]                                       │
│                                                          │
│  ┌────┐ 9월 사전예약                              [ON ●] │
│  │썸네│ 댓글 84 → DM 79 → 답장 41 → 양식 38             │
│  │일  │                                          [수정] │
│  └────┘                                                  │
├──────────────────────────────────────────────────────────┤
│  최근 활동                                                │
│  14:22  @user_a   양식 보냄        9월 사전예약           │
│  13:58  @user_c   건너뜀 · 키워드 불일치   9월 사전예약    │
└──────────────────────────────────────────────────────────┘
```

퍼널 숫자와 전환율·CSV는 Phase 3에서 채운다. 여기서는 **자리와 목록·활동 피드까지**.

**[+ 자동 DM 추가]** 모달 — 입력은 **2개뿐**:
```
게시글 URL   [ https://instagram.com/p/... ]   ← 붙여넣으면 썸네일·캡션 미리보기
보낼 DM      [ 여러 줄 텍스트                ]
▸ 고급 설정 (접힘)  — 발동 키워드 / 1차 확인 문구
```

### 4. 지켜야 할 것 ([`why.md`](./why.md) 원칙 1)
- [ ] 화면에 "캠페인 / 트리거 / 시퀀스" 같은 도메인 용어가 없다 → "자동 DM", "게시글"
- [ ] 필수 입력은 2개를 넘지 않는다
- [ ] 활동 피드에 **댓글·DM 본문을 표시하지 않는다.** 시각 · username · 무슨 일 · 어느 게시글까지만
- [ ] `건너뜀` 행에는 사람이 읽는 이유를 붙인다 ("키워드 불일치" / "본인 댓글" / "이미 보냄" / "꺼져 있음")

## 검증

- [ ] 새 계정으로 가입 → 연결 → 자동 DM 추가 → 실제 댓글 → DM 도착까지 **내가 처음부터 끝까지**
- [ ] **지인 1명에게 링크만 주고 시켜본다.** 어디서 멈추는지, 뭘 물어보는지 전부 기록
- [ ] 다른 계정 데이터 접근 시도 → 차단되는지
- [ ] 최근 50개 밖 게시물 URL → 후보 목록 폴백이 뜨는지
