## 1. LLM 내러티브 요약 ★

**"통계가 어렵다"에 가장 직접적으로 답하는 기능.** Phase 3에서 표와 숫자로 먼저 지인 반응을 본 뒤 붙인다.

핵심은 역할 분리다 — **SQL이 숫자를 계산하고, LLM은 문장만 쓴다.**
LLM은 이미 계산된 JSON을 받아 한국어로 옮기기만 하므로 **숫자 환각이 구조적으로 불가능하다.**

> "이번 주는 '9월 사전예약'이 가장 잘 됐어요. 댓글 84개 중 41명이 답장해서 답장률 52%인데,
> 지난주 평균 38%보다 14%p 높아요. 반응한 사람의 68%는 이미 팔로워였고,
> DM이 안 나간 5건은 전부 키워드가 안 맞아서예요."

- [ ] Phase 3의 집계 결과를 그대로 JSON으로 넘긴다. **원본 행이나 스키마를 넘기지 않는다**
- [ ] 실패하면 조용히 표로 폴백. 요약이 없다고 화면이 깨지면 안 된다
- [ ] 모델은 `claude-opus-5` (`@anthropic-ai/sdk`). 매 대시보드 로드마다 돌리면 `claude-haiku-4-5` 검토
- [ ] API 키는 Secrets Manager

**비용**: 요약 1건 = 입력 ~800토큰 + 출력 ~200토큰 ≈ **$0.009**.
5명 주간이면 월 $0.2, 매일 돌려도 월 $1.4. 비용은 판단 요소가 아니다.

### 자연어 질의(text-to-SQL)는 하지 않는다

"지난달 20대 여성 반응은?" 같은 질의는 더 인상적이지만, **틀린 SQL이 그럴듯한 답을 내면
신뢰가 한 번에 무너진다.** 넣더라도 파라미터만 바뀌는 화이트리스트 쿼리 위에서만.
